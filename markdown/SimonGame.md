# Simon Game

A browser-based implementation of the classic **Simon memory game** built with **JavaScript, HTML, and CSS**. The project demonstrates event-driven gameplay, sequence generation, and interactive audio/visual feedback.

Try it:  
https://michaelgalloway404.github.io/SimonGame/

## Overview

Players must repeat an increasingly long sequence of colored button presses generated by the computer. Each round adds a new step to the sequence, testing the player’s memory and reaction accuracy.

## Key Features

- **Randomized sequence generation** with increasing difficulty
- **Player input validation** against the generated sequence
- **Visual and audio feedback** for button presses
- **Game state management** including level progression and game over conditions
- **Start/reset functionality**
- Custom **sounds and visual assets**

## Technical Highlights

- Sequence tracking using **arrays for player and computer inputs**
- **Event-driven input handling** via DOM event listeners
- **Timed animations and sound playback**
- Logic to prevent repetitive sequences (e.g., avoiding triple repeats)

## Technologies Used

- JavaScript
- HTML
- CSS
